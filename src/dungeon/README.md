# Dungeon

Here is where we store the `!dungeon` commands listed in the workshop.

For example `!dungeon begin` is in the file /src/dungeon/begin.alias. Starting floor per `-difficulty` can be overridden with the `DowntimeDungeon_difficulty_start_floors` server variable (see the root [README](../../README.md#difficulty-start-floors)).

`!dungeon` by itself is an alias to `!dungeon floor`.
